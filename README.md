# Паучий Двор — Spider Solitaire

Классический «Паук» (1/2/4 масти) с системой скинов стола/рубашки карт,
галереей открываемых портретов и премиум-подпиской на реальных платежах
через Stripe.

- `index.html` — вся игра (один файл, работает и офлайн, и в браузере, и
  внутри Electron-обёртки для desktop).
- `api/create-checkout-session.js` — серверная функция, создающая
  Stripe Checkout Session.
- `api/verify-session.js` — серверная функция, проверяющая, что оплата
  реально прошла, прежде чем разблокировать премиум на клиенте.

GitHub Pages умеет отдавать только статику, поэтому папку `api/` нужно
задеплоить туда, где может выполняться серверный код. Проще всего — **Vercel**,
он бесплатен для такого объёма трафика и подключается прямо к GitHub-репозиторию.

## 1. Залить проект на GitHub

```bash
cd spider-yard
git init
git add .
git commit -m "Initial commit: Spider Solitaire with skins and premium"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/spider-yard.git
git push -u origin main
```

(Замени `ТВОЙ_ЛОГИН` и, если нужно, имя репозитория — создай пустой
репозиторий на github.com заранее, без README/лицензии, чтобы не было
конфликтов при первом push.)

## 2. Настроить Stripe

1. Зарегистрируйся на [stripe.com](https://stripe.com) (или используй
   существующий аккаунт).
2. В разделе **Product catalog** создай продукт, например «Premium skins»,
   с разовой ценой (one-time price). Скопируй его **Price ID**
   (выглядит как `price_1AbCdEfGhIjKlMnOp`).
3. В разделе **Developers → API keys** скопируй **Secret key**
   (`sk_test_...` для тестового режима, `sk_live_...` для боевого).

## 3. Задеплоить бэкенд на Vercel

1. Зайди на [vercel.com](https://vercel.com), войди через GitHub.
2. **Add New Project** → выбери репозиторий `spider-yard`.
3. Framework Preset можно оставить «Other» — Vercel сам подхватит папку
   `api/` как serverless-функции.
4. В **Environment Variables** добавь (см. `.env.example`):
   - `STRIPE_SECRET_KEY`
   - `STRIPE_PRICE_ID`
   - `SITE_URL` — публичный URL твоего проекта на Vercel
     (например `https://spider-yard.vercel.app`); его увидишь после
     первого деплоя, потом можно передеплоить с уже правильным значением.
5. Нажми **Deploy**.

После деплоя игра и бэкенд будут жить на одном домене — специально
настраивать `API_BASE` в `index.html` не нужно, оставь его пустой строкой
(так и есть по умолчанию), запросы пойдут на тот же домен `/api/...`.

## 4. Проверить оплату

1. Открой задеплоенный сайт, нажми «Купить премиум».
2. Пройди тестовую оплату Stripe (в тестовом режиме используй карту
   `4242 4242 4242 4242`, любую будущую дату и любой CVC).
3. После оплаты Stripe вернёт тебя на сайт с `?session_id=...` в адресе —
   игра сама проверит оплату через `/api/verify-session` и разблокирует
   премиум-скины (сохраняется в `localStorage` браузера).
4. Когда всё проверено — переключи `STRIPE_SECRET_KEY` и `STRIPE_PRICE_ID`
   на боевые (`sk_live_...`) значения в Environment Variables на Vercel.

## Про desktop-версию (Electron)

`index.html` можно завернуть в Electron, чтобы получить `.exe`/`.app`.
Учти нюанс: поток оплаты Stripe Checkout открывается как обычная
веб-страница — в Electron для этого удобнее открывать системный браузер
(`shell.openExternal`) на шаге оплаты, а после успешной оплаты попросить
пользователя вернуться в приложение (или сделать глубокую ссылку
`spiderd yard://` обратно в приложение). Если нужно — могу собрать
Electron-обёртку с этим сценарием отдельным шагом.

## Локальная разработка без Stripe

Если бэкенд ещё не задеплоен, кнопка «Купить премиум» просто покажет
сообщение об этом — игра при этом полностью играбельна, доступен
бесплатный скин «Изумрудный двор».
